# Color Contrast

- WCAG 2.1 AA requires 4.5:1 for normal text, 3:1 for large text (18pt or 14pt bold).
- Don't rely on color alone; use icons or text labels too.
- Use devtools to check contrast ratios quickly.
- Test with grayscale and color blindness simulators.
